## Projects

### 1. Multimodal Human Activity Recognition (Thermal + Pose)

![HAR Pipeline](assets/har_pipeline.png)

**Problem**  
Privacy-preserving activity recognition without RGB data  

**Approach**  
- Thermal + pose encoders  
- Attention / gating-based fusion  
- **Confidence-aware fusion (CGCA, CGHCA)**  

**Results**  
- Multimodal > unimodal  
- Robust under modality uncertainty  

![HAR Results](assets/har_results.png)

**Contribution**  
Reliability-aware multimodal fusion for structured sensor data

### 2. Multi-View Representation Learning for Neuronal Morphology

![Morphology Pipeline](assets/morph_pipeline.png)

**Problem**  
Single-view representations miss structural complexity  

**Approach**  
- Graph (topology) · Point (geometry) · Voxel (volume)  
- Unified embedding with **Morphogenesis Fusion**  

**Results**  
- Multi-view > best uni-view  
- Improved latent structure  

![Morphology Results](assets/morph_results.png)

**Contribution**  
Representational complementarity in biological structures
